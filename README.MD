# Mongolian LLM Evaluation

## Research Question

Do LLMs perform differently on natively authored Mongolian prompts than on semantically equivalent translated Mongolian prompts?

## Hypotheses
H1: LLM performance differs between natively authored and translated Mongolian prompts.

H2: The size of this difference varies by task type.
